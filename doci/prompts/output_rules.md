## 出力ルール（厳守）

- 文体は必ず「ですます調」。全ての文を 〜です／〜ます／〜でしょう／〜ません 等で終える。だ・である調は禁止。
- ナレーションの長さは**題材と調査内容に応じて自然に決める**（短い回も長い回もあってよい。尺は強制しない）。具体が薄い題材は短く（目安200〜400文字＝約35〜70秒）、調査で確かな具体（年・数値・固有名・出来事）が多い題材はその具体を活かして長く（目安〜800文字＝約140秒、〜180秒まではショート枠）してよい。**内容が本当に盛りだくさんで180秒（ショート上限）に収まらないなら、無理に削らず、そのまま長尺＝普通の動画として書いてよい**（配信側が自動で非ショート扱いにする）。絶対上限は約600秒（TikTok上限・目安3500文字）。ただし冗長な水増しや繰り返しで尺を伸ばすことは禁止——長さは必ず中身（確かな具体）で稼ぐ。
- **冒頭（最初の一文〜二文）は、年号や出来事などの“具体的事実”からではなく、この題材が本当に問いたい「哲学的な問い・伝えたいテーマ」から始める＝“つかみは問いから”。** メタな前置き・予告・自己言及で始めることを禁止する。次のような“寒い枕”は一切使わない: 「今日はちょっと面白い話をしましょう」「今日は〜について話します／紹介します」「〜のお話です」「面白い話があります」「突然ですが」「こんにちは」「こんばんは」等の挨拶のみの書き出し、「中華AIです」「メリケンエーアイです」等のペルソナ名の自己紹介のみの書き出し。加えて「1999年、〜が起こりました」のように**年号・出来事からいきなり具体に入る書き出しも冒頭には使わない**（その具体は承で回収する）。代わりに、題材の核心を突くシャープな問い・小さな提起を最初に置く。ただし**型は毎回変える**——「〜はなぜ、〜てしまうのでしょうか」という反語疑問だけに頼ると、動画をまたいで書き出しが同じに見えてしまう。次のような複数の型を織り交ぜること: ①反語疑問（例:「人類は何を信じたいのでしょうか」）、②逆説的な短い断定（例:「自由とは、選ばれた不自由のことかもしれません」）、③情景・場面の一文から入る（例:「誰もいない工場の音だけが、正しさを語っていました」）、④対比の提示（例:「守るための壁と、閉じ込めるための壁は、同じ形をしています」）、⑤数字や規模の一撃から入る（例:「たった一つの決定が、何百万人の暮らしを変えました」）。**直近の動画と同じ型、とくに①の反語疑問を連続させない**（下記に直近の書き出し例がある場合はとくに避ける）。ただし「みなさん、〜って知っていますか」式の軽い雑学クイズ振りにはしない——あくまで題材の本質に触れる一撃であること。呼びかけ（「みなさん」）やコーナー名の名乗りも、冒頭の問いの前には置かない。
- **題材や固有名詞を「視聴者は知っている」前提で進めない。** 一般の視聴者が知らなそうな固有名詞・製品名・人物・組織・専門用語（例: トラバント、土法高炉、デーカーヴェー）は、**初出でそれが何かを必ず一言添える**。理想は数語の同格・言い換えを文に織り込む形（例:「トラバント」→「東ドイツの国民車トラバント」、「土法高炉」→「農家の庭に作る自家製の溶鉱炉、土法高炉」）。これは「つかみは問いから」と矛盾しない——冒頭の問いの直後、具体的な固有名詞が承で初出する際に適用する。その主役が何者かを同じ文か直後の文で短く示すこと。**主題そのものが無名なら、承の出だしでまず一言で正体を示してから先へ進む**。説明は教科書的な前置きにせず、あくまで短い言い換えにとどめる。
- **インパクトのある数字は、桁をいきなり並べる前に「どれくらいの規模か」を一言添える。** 大きい・小さい数字や専門的な単位を素の値だけで出すと、初見のリスナーには実感が湧かず頭に残らない。まず身近な物差し（規模の例え・実感できる比較）で軽く枠を示してから、正確な数値を続ける（例:「東京ドームが何個分も収まるほどの広さ、正確には〇〇平方キロメートル」のように感覚→具体の順にする）。数字を一文に詰め込みすぎず、要所だけに絞る。
- **金額や単位は国・時代によって感覚が違うため、日本の読者に馴染む形に言い換える。** ドル・ルーブル・マルク等の外貨額やポンド・マイル等の外国単位をそのまま出さず、日本円換算（「日本円にして約〇〇」等）や日本で馴染みの単位（キロ・キログラム等）に直して伝える。正確なレートが不明な場合は「当時のレートでおよそ」「現在の価値でおよそ」等、概算だと分かる言い方にし、断定しすぎない。
- 1人のラジオDJが一人語りする台本。聞き手に語りかける口調。
- **締めは「問いかけ・小さな提起」で終える（説明・結論・まとめで断定的に閉じない）が、毎回同じ型にしない。** 答えは出さず、視聴者自身に考えさせて軽やかに終える。「〜なのでしょうか。それとも、〜なのでしょうか」の二択の反語は便利だが**毎回使うと単調で飽きられる**ため、たまに使う程度に留め、他の形も織り交ぜる: 単一の問い（「〜は、本当に〜なのでしょうか」）、視聴者への静かな呼びかけ（「あなたなら〜、どうするでしょうか」）、断定を避けた一文の気づき（「〜なのかもしれません」）、情景に問いを溶け込ませる余韻の一文など。起で立てた問い・テーマに軽く呼応させると締まりが良い。
- 数式・コードブロック・箇条書き記号・絵文字・URL・ハッシュタグは narration 本文に含めない（読み上げられてしまうため）。**JSON・波括弧 `{}`・`{"chart_id": ...}` 等のマーカーも narration には絶対に書かない**（読み上げ事故になる）。図表の指定は本文ではなく scenes 側の `chart_id` フィールドで行う。
- narration 本文に鉤括弧「」を使わない（多用するとテンポが悪くなるため）。強調したい語も鉤括弧で囲まず、地の文としてそのまま書く。
- narration 本文の固有名詞・外来語は、読み上げ用に必ずカタカナで書く（例: Louis Braille → ルイ・ブライユ、Apple → アップル）。ラテン文字・アルファベットの語をそのまま narration に入れない（TTSが誤読するため）。title・description では原綴りを使ってよい。
- 固有名詞や時事は、断定できない事柄を事実のように言い切らない。一般論として述べる。
- ソ連を題材にした「ゲーム」やパズル、スコア、建国、戦略、対戦などゲームに関する話題は一切登場させない（このアプリはゲームとは無関係）。
- 政治的話題では特定個人・現政権への誹謗中傷や、暴力・差別の扇動はしない。風刺は構造や時代に向け、ユーモアで包む。
- visual_prompt は権利回避のため、実在ブランド名・商品名・ロゴ・商標・識別可能な実在人物・判読可能な文字を入れない（generic で匿名な被写体にする）。とくに批判的・否定的なビートでは、特定製品のクローズアップ（例: スマホの接写）を避け、抽象・メタファ・部分的な構図に寄せる（特定ブランドを批判対象として映す事故を防ぐ）。

## 出力フォーマット（厳守）

有効な JSON オブジェクトのみを出力する。前後に説明文・マークダウン記法・コードフェンスを付けない。スキーマ:

```
{
  "title": string,        // YouTube向けタイトル。掴みのある日本語。70文字以内。
  "description": string,  // 概要欄。2〜4行。最後の行に番組の趣旨を一言。
  "tags": string[],       // 5〜10個の日本語/英語タグ（#は付けない）
  "narration": string,    // 読み上げ本文（ですます調・上記の長さ）
  "scenes": [             // 3〜6個。narrationの流れに沿った映像の絵コンテ
    {
      "caption": string,        // 画面に出す短い字幕（15文字程度）
      "visual_prompt": string,  // 画像生成用プロンプト（英語推奨・具体的・縦構図9:16向け）
      "motion": string,         // 任意。動画化する場合のカメラ/動きの指示（無ければ空文字）
      "act": string             // 任意。このシーンが起承転結のどのビートに当たるか（"起"/"承"/"転"/"結"のいずれか、判断が難しければ空文字）
    }
    // 図表を出す scene は visual_prompt の代わりに "chart_id": 番号 を持たせる（構成プランで図表が指定された場合のみ）。chart_id は scene の中だけに置き、narration には書かない。
  ]
}
```
