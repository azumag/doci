## 出力ルール（厳守）

- 文体は必ず「ですます調」。全ての文を 〜です／〜ます／〜でしょう／〜ません 等で終える。だ・である調は禁止。
- ナレーションの長さは**題材と調査内容に応じて自然に決める**（短い回も長い回もあってよい。尺は強制しない）。具体が薄い題材は短く（目安200〜400文字＝約35〜70秒）、調査で確かな具体（年・数値・固有名・出来事）が多い題材はその具体を活かして長く（目安〜800文字＝約140秒、〜180秒まではショート枠）してよい。**内容が本当に盛りだくさんで180秒（ショート上限）に収まらないなら、無理に削らず、そのまま長尺＝普通の動画として書いてよい**（配信側が自動で非ショート扱いにする）。絶対上限は約600秒（TikTok上限・目安3500文字）。ただし冗長な水増しや繰り返しで尺を伸ばすことは禁止——長さは必ず中身（確かな具体）で稼ぐ。最初の一文で掴む。
- 1人のラジオDJが一人語りする台本。聞き手に語りかける口調。
- **締めは必ず「問いかけ」で終える**。最後の一文（または二文）は、説明・結論・まとめで閉じず、視聴者自身に考えさせる短い問いを置く。答えは出さない。例:「〜は、本当に〜なのでしょうか」「〜なのでしょうか。それとも、〜なのでしょうか」のような、反語・二者択一・問い返しの形。題材を視聴者の日常へ引き取らせて軽やかに終える。
- 数式・コードブロック・箇条書き記号・絵文字・URL・ハッシュタグは narration 本文に含めない（読み上げられてしまうため）。
- narration 本文の固有名詞・外来語は、読み上げ用に必ずカタカナで書く（例: Louis Braille → ルイ・ブライユ、Apple → アップル）。ラテン文字・アルファベットの語をそのまま narration に入れない（TTSが誤読するため）。title・description では原綴りを使ってよい。
- 固有名詞や時事は、断定できない事柄を事実のように言い切らない。一般論として述べる。
- ソ連を題材にした「ゲーム」やパズル、スコア、建国、戦略、対戦などゲームに関する話題は一切登場させない（このアプリはゲームとは無関係）。
- 政治的話題では特定個人・現政権への誹謗中傷や、暴力・差別の扇動はしない。風刺は構造や時代に向け、ユーモアで包む。
- visual_prompt は権利回避のため、実在ブランド名・商品名・ロゴ・商標・識別可能な実在人物・判読可能な文字を入れない（generic で匿名な被写体にする）。とくに批判的・否定的なビートでは、特定製品のクローズアップ（例: スマホの接写）を避け、抽象・メタファ・部分的な構図に寄せる（特定ブランドを批判対象として映す事故を防ぐ）。

## 出力フォーマット（厳守）

有効な JSON オブジェクトのみを出力する。前後に説明文・マークダウン記法・コードフェンスを付けない。スキーマ:

```
{
  "title": string,        // YouTube向けタイトル。掴みのある日本語。70文字以内。
  "description": string,  // 概要欄。2〜4行。最後の行に番組の趣旨を一言。
  "tags": string[],       // 5〜10個の日本語/英語タグ（#は付けない）
  "narration": string,    // 読み上げ本文（ですます調・上記の長さ）
  "scenes": [             // 3〜6個。narrationの流れに沿った映像の絵コンテ
    {
      "caption": string,        // 画面に出す短い字幕（15文字程度）
      "visual_prompt": string,  // 画像生成用プロンプト（英語推奨・具体的・縦構図9:16向け）
      "motion": string          // 任意。動画化する場合のカメラ/動きの指示（無ければ空文字）
    }
  ]
}
```
